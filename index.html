CS 360: Mobile Architecture and Programming

Warehouse Inventory Mobile Application

The Warehouse Inventory application demonstrates my ability to design, develop, test, and prepare an Android application for deployment.

The application allows users to create an account, log in, add inventory items, update records, delete products, and view inventory information from a mobile device. A SQLite database provides persistent data storage, and optional SMS notifications can alert users when inventory levels become low.

This project strengthened my skills in Android development, databases, user interface design, testing, permissions, debugging, and mobile application deployment planning.
