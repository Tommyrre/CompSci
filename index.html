Enhancement One: Software Design and Engineering

My Software Design and Engineering enhancement focused on improving the overall architecture of the CS-340 Animal Shelter Dashboard.

I converted the original Jupyter Notebook into a modular Dash application and separated configuration, repository access, business logic, layouts, and callbacks into individual components.

I also removed hard-coded credentials, added environment-based configuration, improved logging and exception handling, added validation, and reorganized the project into a cleaner structure. These changes improved maintainability, readability, scalability, and security.

Enhancement Two: Algorithms and Data Structures

My Algorithms and Data Structures enhancement focused on improving how data is searched, filtered, sorted, processed, and displayed throughout the dashboard.

I implemented multi-field keyword searching, advanced filtering, ascending and descending sorting, pagination, reusable filtering functions, caching, record counting, and optimized callback processing.

CS-360 Mobile Architecture & Programming

Warehouse Inventory Mobile Application

My Warehouse Inventory Mobile Application demonstrates my experience designing, developing, testing, and preparing an Android mobile application for deployment.

The application provides users with a simple way to manage inventory directly from a mobile device. Users can create an account, log in, add inventory items, update existing records, remove products, and view inventory information in one place.

The application also includes optional SMS notifications for low inventory levels. If SMS permission is denied, the remaining application functionality continues to work normally.
